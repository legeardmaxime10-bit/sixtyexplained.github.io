Privacy Policy

Last updated: 20 November 2026

This policy covers the website for 60s Explained and the "60s Explained Uploader" application, a private tool the channel owner uses to publish videos to the 60s Explained YouTube channel.

Who uses the application

The application is used only by the owner of the 60s Explained channel, for that channel. It is not offered to the public, and no one else signs in to it. It publishes the channel's own videos to YouTube, TikTok and Instagram.

Google and YouTube data the application accesses

When the channel owner signs in with Google, the application requests permission to:

  • upload videos to the owner's own YouTube channel (youtube.upload);
  • read the channel's own videos, statistics and subscriber count (youtube.readonly);
  • read the channel's own YouTube Analytics reports, such as average view percentage (yt-analytics.readonly).

This data is used only to publish the channel's videos and to measure how they perform so that future videos can be improved. It is stored only on the owner's own computer. It is not sold, shared with third parties or used for advertising, and it is not used to train AI models.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

YouTube

The application uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

TikTok data the application accesses

When the channel owner signs in with TikTok, the application requests permission to read the account's basic profile (user.info.basic) and to upload videos to the owner's own TikTok inbox as drafts (video.upload). The owner reviews and publishes each draft in the TikTok app. Sign-in tokens are stored only on the owner's computer and are not shared, sold or used for advertising. Access can be revoked in the TikTok app under Settings → Security → Manage app permissions.

Instagram and Facebook data the application accesses

When the channel owner signs in with Facebook, the application requests permission to list the owner's Facebook Page and its linked Instagram professional account (pages_show_list, pages_read_engagement, instagram_basic) and to publish Reels to that account (instagram_content_publish). Tokens are stored only on the owner's computer and are not shared, sold or used for advertising. Access can be revoked at any time in Facebook Settings → Business integrations.

Visitors to this website

This website has no accounts, forms, cookies or analytics, and it collects no personal data from visitors. The hosting provider may keep standard server logs, such as IP addresses, for security.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked, the locally stored sign-in token stops working and is deleted.
